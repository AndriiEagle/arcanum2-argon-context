# Arcanum 2 — context pack for external art/design models

Public, curated context so a web model (Gemini "Argon 4" or similar) can draw and design for this game in its exact
style. No game code, no private material — only canon, style, samples and three isolated evaluation prompts.

## Three ways to give it to a model (pick the first that works)
1. **Web page with everything and the images inline:** https://andriieagle.github.io/arcanum2-argon-context/
2. **One plain file:** https://raw.githubusercontent.com/AndriiEagle/arcanum2-argon-context/master/ALL_IN_ONE.md
   (or upload `ALL_IN_ONE.md` + a few `samples/*.png` into the chat). All raw links: `LINKS.md`.
3. **Zip for manual upload:** the latest release of this repository, `arcanum2-argon-pack.zip`.

Web chat models often cannot walk a GitHub repository tree from its address; a single page or a single raw file works.

```
WORLD_BIBLE.md                 condensed world/genre/visual law (start here)
ART_BIBLE.md                   light, palettes, temperatures per location
SPEC_CH1_v0.md                 chapter-1 systems: day cycle, energy, habits, craft
prompts/PROMPT_1..3_*.md       three isolated evaluation prompts; prompts/README.md = how answers are accepted
samples/                       real 1280x720 playtest frames (what the game looks like today)
ALL_IN_ONE.md, LINKS.md, docs/ generated by build_pack.py — rebuild after any change
```
